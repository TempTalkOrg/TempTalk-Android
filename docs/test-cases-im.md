# IM 功能冒烟测试用例

> 发版前 IM 模块功能回归验证。
> 自动化方案：Maestro + Claude AI 截图对比（详见 `.claude/skills/smoke-test-im/SKILL.md`、`maestro/flows/`）

## 状态说明

| 标记 | 含义 |
|------|------|
| `AUTO` | 已有 Maestro 脚本自动化 |
| `TODO` | 计划自动化，尚未实现 |
| `MANUAL` | 需人工验证（无法自动化或性价比低） |
| `SKIP` | 故意跳过自动化（如功能无法在 receiver 端验证、价值低） |
| `N/A` | 该消息类型不支持此操作（按 `MessageActionConfigBuilder`） |

## 概念说明

- **基本消息类型**（6 种）：文本、图片、语音、视频、文件、联系人
- **机密模式**：可叠加在任意基本消息类型上，开启后消息带遮罩覆盖 + 加密标识。机密不是独立消息类型，而是一个模式开关（`iv_confidential`），与基本类型正交组合。
- **操作**：长按消息呼出的上下文菜单操作（引用、复制、转发、翻译等）
